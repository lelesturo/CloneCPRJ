Crea CPRJ Montante v2.1.1
Data: 2026-04-23

Correzione v2.1.1
- LABEL_BCU: viene sostituito l'intero contenuto dell'attributo text="", non solo il montante contenuto nella label.
- La sostituzione tiene conto della sostituzione globale del montante gia' applicata prima di aggiornare states.ccx.
- Esempio: text="BMUAS1 LINEA 311 LACCHIARELLA 3M11 DCO" puo' diventare text="ETICHETTA COMPLETA NUOVA AS1 3M12 XYZ".

Novita'
- La tab "Sostituzioni Generiche" ora accetta anche un singolo file come sorgente.
- Il file singolo viene modificato solo se rilevato come testo, usando la stessa logica gia' usata per i file dentro i .cprj.
- Per i file singoli l'output viene scritto nella cartella output configurata, senza modificare il file originale.
- Se "Nome file output" e' vuoto, il nome viene derivato dal file sorgente applicando la sostituzione principale al nome file.
- Se il nome sorgente non contiene il Find principale, il nome output diventa il valore di Replace con la stessa estensione del sorgente.
- Se "Nome file output" e' valorizzato, viene usato quel nome esatto.
- La tab CSV accetta una quarta colonna Label opzionale.
- La Label viene usata solo per righe AS/AS1 e aggiorna l'attributo text di <InputState state="LABEL_BCU" ... /> in states.ccx.

Compatibilita'
- Il comportamento .cprj/.zip della v2.0 resta invariato.
- La tab "Progetti da CSV" resta dedicata ai template .cprj/.zip o cartelle template.
- La CLI permette file singoli senza obbligare il parametro --ip.
- I CSV a 3 colonne Montante;Dispositivo;IP restano supportati.

Esempio CLI file singolo
  CreaCprjMontante.exe --source config.txt --out GENERATI --template ACLE --name ACEL

Note operative
- I file rilevati come binari non vengono modificati.
- Il file sorgente originale non viene sovrascritto.
